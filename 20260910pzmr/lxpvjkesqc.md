# 试管养囊一般是5-7天出结果吗？

> 更新时间：2026-09-10 (UTC+8)

是的，试管养囊一般在5-7天就会出结果。因为养囊第3天就会有囊胚的生长，有的囊胚生长的较慢，可能会在7天的时候也会出现生长，所以试管养囊一般在5-7天就会出结果。养囊是指将第3天的胚胎继续体外培养到第五天甚至第六天或更多，胚胎会成长为有囊胚腔的细胞团，这就叫囊胚。这整个的全过程就叫做养囊。一般来说，囊胚经培养后，可提高其胚胎着床率，降低妊娠丢失率。临床上，医生将囊胚的等级分为6级，分别是1级、2级、3级、4级、5级以及6级，囊胚质量越高，等级越大，也就是说，6级囊胚是最好的。

囊胚等级分类

- 1. 1级代表为初级囊胚，囊胚腔小于胚胎总体积的1/2，怀孕率为20-30%；
- 2. 2级代表为初期囊胚，囊胚腔大于或等于胚胎总体积的1/2，怀孕率为30-40%；
- 3. 3级代表为扩张囊胚，囊胚腔逐渐向整个胚胎扩展，怀孕率为40-50%；
- 4. 4级代表为扩张囊胚，囊胚腔完全充满胚胎，胚胎总体积变大，透明带边薄，怀孕率50-60%；
- 5. 5级代表正在孵化的囊胚，囊胚的一部分从透明带中逸出，怀孕率60-70%；
- 6. 6级代表已经孵化的囊胚，囊胚全部从透明带中逸出，怀孕率60-70%。

内细胞团分级

- 1. A级代表细胞数目多，排列紧密，上皮细胞层由较多的细胞组成，结构致密；
- 2. B级代表细胞数目少，排列松散，上皮细胞层由不多的细胞组成,结构松散；
- 3. C级代表细胞数目很少，上皮细胞层由稀疏的细胞组成。

滋养层细胞分级

- 1. A级代表上皮细胞层由较多的细胞组成，结构致密；
- 2. B级代表上皮细胞层由不多的细胞组成，结构松散；
- 3. C级代表上皮细胞层由稀疏的细胞组成。

试管养囊在5-7天就会出结果。其中6aa囊胚属于质量最好的囊胚，1aa囊胚属于质量最差的囊胚。建议患者在试管期间，要放松心情，不要给自己太大的压力。
